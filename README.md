            <p>La compañía ha centrado esta característica para aquellos profesionales que trabajan extensamente con documentos, especialmente en el ámbito legal, financiero y de edición iterativa, como ha explicado en su página de soporte.</p>

El asistente de Anthropic proporcionará respuestas siempre en base al contenido del texto con <b>citas interactivas para una localización más rápida.</b></p>
            <br>
            <p>Claude también es capaz de leer los hilos de comentarios dentro del documento, entendiendo a qué texto está anclado cada uno y trabajando con ellos de forma individual.</p>
            <br>
            <p>Otra de las funciones que integra el complemento es la edición de textos. De esta forma los usuarios pueden <b>pasarle una cita a Claude e indicarle qué cambios realizar</b> para, por ejemplo, cambiar el estilo con el que está redactado, matizar detalles, entre otros.</p>

Por otra parte, los usuarios pueden crear plantillas para que Claude se ajuste a este tipo de formatos y pueda replicarlos cuando genere el contenido.</p>
